# Security Policy

## Supported versions

The latest `1.x` release is supported.

## Reporting a vulnerability

Please report vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/Diaszano/TFT_eSPI_ESP8266/security/advisories/new). Do not report security issues in public issues.

We will acknowledge reports within 7 days.

## Scope

This library runs on the device and has no network-facing surface. Reports in scope include:

- Buffer overflows or out-of-bounds reads while processing external data, including `.vlw` fonts, sprites and images.
- Supply-chain risks in GitHub Actions workflows or the release process.
